# 入力欄のコマンド・参照・補完

## 使い方

| 入力 | 動作 |
|---|---|
| `/skills` または `/スキル名` | 接続先の有効なスキルを検索・指定 |
| `/plugins` | インストール済みで有効なプラグインを指定 |
| `@file` または `@README` | 現在のプロジェクト／タスクのworktree内のファイルを検索 |
| `@agent` | default / explorer / workerへの委任依頼を指定 |
| `/plan` または `@plan` | Codexのプランモード |
| `/goal` または `@goal` | 送信する依頼文をCodexのゴールとして設定 |
| `/implement` | 通常の実装モード |
| `/workflow` | 独自の構造化実行計画を作成 |
| `/history` | このプロジェクトの入力履歴を選択 |

候補を上下キーで選び、EnterまたはTabで採用します。Escで閉じます。日本語変換中のEnterは候補を採用しません。選んだ参照は入力欄の下に表示され、×で解除できます。参照の選択だけではタスクを実行しません。送信は実行ボタンまたは⌘Enterです。

スキル・プラグイン・モード・エージェントの利用にはCodexモデルを選択してください。ファイル参照はローカル編集の対象ファイルにも反映します。候補はGit管理対象と未追跡ファイル（ignore対象を除く）から取得し、プロジェクト外へのパスやシンボリックリンクは拒否します。

## 2種類の計画

以前の「計画する」はCodexのプランモードではありませんでした。現在は次の2つを区別します。

- **プランモード（Codex）**: `turn/start.collaborationMode.mode=plan` を送信し、選択したモデル・Reasoningを維持します。Codexからの質問には画面で回答できます。実装へ移る際は操作を切り替えます。
- **実行計画を作る**: 既存のPlanタブに構造化した実行計画を生成する機能です。`/workflow` でも選べます。

ゴールは `thread/goal/set` で登録してからターンを開始します。トークン予算は自動設定しません。画面にゴールの状態を表示し、一時停止できます。

`@agent` は指定した種別への委任依頼をモデルへ渡します。アプリが直接エージェントを起動する操作ではありません。実際の起動は接続先の機能・適用されるAGENTS.md等の制約に従います。モデルの切替や制約の上書きは行いません。カスタムエージェントの列挙には未対応です。

## 入力補完

既定では、このアプリに保存したプロジェクト別の入力履歴から続きを提案します。過去のタスクを開くと、その画面に読み込まれた直近のユーザー入力も履歴に追加します。Codex全体の非公開履歴を一括取得する機能ではありません。履歴は最大100件です。

候補を表示しても入力は変わりません。Tabで続きだけを採用します。入力やタスクが変わった後に届いた候補は捨てます。

「補完設定」でAI補完を有効にすると、履歴に一致しない入力に対してLunaが続きを提案します。入力停止から1.4秒後、前回から12秒以上空けてリクエストします。手動のAI補完ボタン／Ctrl+Spaceも使えます。送信内容は現在の入力と同じプロジェクトの履歴最大6件（各700文字）です。候補は最大320文字、生成待ちは20秒です。

補完は作業用タスクと別の一時セッションで行い、リポジトリ本文は渡しません。環境アクセス、シェル、プラグイン、MCP、ブラウザー、サブエージェント等を無効化します。秘密情報らしい入力は送信前に拒否しますが、あらゆる秘密情報を検出できるという保証ではありません。

2026-09-08の実接続では `gpt-5.6-luna` の対応Reasoningは low / medium / high / xhigh / maxで、noneは非対応でした。noneをlowに黙って置換せず、AI補完は無効のままです。利用する場合は設定で対応値を選択し、有効化してください。
