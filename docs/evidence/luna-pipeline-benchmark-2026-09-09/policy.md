# Task scheduler contract
Implement scheduler.py with three public functions: topological_order(tasks), execution_batches(tasks, max_parallel), critical_path_length(tasks).
`tasks` is a dict mapping nonempty string IDs to dicts containing exactly: deps (list of task ID strings), duration (positive integer, bool forbidden), group (None or nonempty string). Empty task dict is valid. Duplicate dependencies are treated as one dependency. Never mutate input.
All three functions must reject invalid schema, unknown dependencies, self-dependencies, and any directed cycle with ValueError. Reject malformed tasks or fields with ValueError (not TypeError/KeyError). execution_batches additionally rejects max_parallel unless it is a positive integer and not bool, including when tasks is empty.
topological_order returns a list of all IDs. At each choice select the lexicographically smallest currently ready task, including tasks newly enabled by that choice. Do not precompute fixed readiness waves for this function.
execution_batches returns list[list[str]]. Each batch starts from tasks whose dependencies finished in earlier batches. Sort those ready IDs lexicographically, scan once, and greedily append up to max_parallel tasks. A non-None group may occur at most once per batch; None is unrestricted. Skip group conflicts and continue scanning so later compatible tasks fill slots. Tasks enabled by the current batch wait for the next batch. Durations do not affect batch construction.
critical_path_length returns the largest sum of durations along a dependency path, disregarding group and max_parallel constraints. Return 0 for no tasks.
Only create scheduler.py and test_scheduler.py. Python standard library only. No external access or delegation. Read this policy and PLAN.md before implementation. Run your own tests and acceptance.py; do not edit policy.md, PLAN.md, AGENTS.md, or acceptance.py.
