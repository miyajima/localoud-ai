## 95点超えに向けて修正した点

1. サイドバー内にあった開閉ボタンをツールバーへ移動。狭い画面では閉じる操作・背景操作の抑止・Escでの復帰を備えたドロワーにした。
2. 矢印キーでタブを選び、Enter/Spaceで確定する操作へ修正。本文全体のライブ通知を除去し、メッセージ操作とプロジェクト操作のフォーカスを再描画後も維持した。
3. 通常モードで文字を入力しても送信ボタンが無効のままになる不具合を修正。候補がないTabは次の操作へ進むようにした。
4. 小さい文字をrem化し、通常表示の補助文字を12px以上にした。狭幅・タッチ操作は44 CSS px以上を確保。拡大文字で上部の操作が潰れないよう、サイドバー内の縮小を抑止した。
5. 透過したショートカット表示、暗色の削除差分、フォームエラー、入力枠の配色を調整。白／青の主操作は5.33:1、暗色の削除差分は5.11:1、明色の入力枠は3.86:1。
6. 使用量・差分・参照情報・計画の読込状態を追加。未取得を0件と扱わず、失敗時は保存済み表示を残す。遅れて返った別タスクのエラーを現在の画面に出さない。
7. 項目別エラーとリンク付きエラー要約を追加。設定の取得前は保存を禁止し、保存中の重複操作を防止。部分保存後の失敗も区別する。履歴削除には対象名を明示した二段階確認を追加した。
8. 連続イベントをフレーム単位にまとめ、未変更のプロジェクト一覧を作り直さないようにした。保存履歴の再生中も1件ごとの全体描画を止めた。

`ui-ux-pro-max` のフォーカス、エラー回復、文字拡大、タッチ操作、配色の指針を適用。元の「Macらしいコンパクトな作業画面」という方向は維持した。

- 対象の表示文字12px未満、表示中の非無効ボタン等のタッチ領域44px未満、文書幅の横溢れ、サイドバー直下の行の重なり: **検出0件**。チェックボックスのラベル領域・非表示領域・ネイティブWebViewはこの自動寸法集計の対象外。

画面は1280×900のライト／ダーク、375×812、812×375、文字200%、reduced-motionで確認。通常依頼、計画実行の各タブ、設定、エラー、コマンド検索、ChatGPTの外枠を含む。

この検証ではネイティブ呼出しをすべてテスト用に置き換え、ブラウザ通信も専用localhostに限定した。LLM実行、課金、実設定変更、実プロジェクトの登録・削除は行っていない。専用サーバーとブラウザは検証後に終了する。

## 再実行

`apps/desktop` で `npm test`、`npm run build`、`npm run test:ui`。

`test:ui` は専用Viteサーバーを起動し、Playwright Chromiumとaxeで確認する。Chromiumが未導入の環境では事前に `npx playwright install chromium` が必要。画像とJSONの保存先は実行終了時に表示される。既存の専用フロントエンドを使う場合は `UI_AUDIT_URL`、保存先を指定する場合は `UI_AUDIT_OUTPUT` を使う。`--baseline` は違反集計の調査用で、合格証拠には使わない。

今回の最終生データ: `/private/tmp/localoud-ui-audit-j3Qb4x/report.json`。一時領域のため永続保管は保証しない。
