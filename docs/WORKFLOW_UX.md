# Localoudの作業フロー

左から「プロジェクト一覧 → ChatGPT → Localoud」。計画とレビューはChatGPT、実行と保存記録はLocaloudで扱います。ChatGPTを使わない直接依頼にも対応します。

## 画面の使い方

- 左のプロジェクト一覧は画面上端まで表示し、プロジェクトの下にタスクを並べます。右端の境界をドラッグすると160〜420pxで幅を変更できます。境界にフォーカスして左右キーでも調整でき、次回起動時も幅を保持します。
- ChatGPTは一覧の右、Localoudの左に表示します。Localoudペインの一番左上の「ChatGPT」ボタン、または `⌘⇧B` で全体を表示・非表示にできます。非表示にすると列の余白もなくなります。
- 進捗は選択したタスクのLocaloudペイン内に、小さく表示します。作業名やプロジェクト名の重複見出しは置きません。
- ChatGPTとLocaloudの境界もドラッグできます。狭い画面では同じ領域で切り替え、Localoud上部のトグルから戻れます。

## ChatGPTで計画する場合

1. プロジェクトを選び、「新しいタスク」の開始方法を「ChatGPTで計画」にします。
2. 左のChatGPTに作業内容・条件を入力し、計画を相談します。
3. 確定したTask ManifestのJSONをコピーし、右のLocaloud上部で「計画を取り込んで実行」を押します。
4. 実行中はLocaloudの進捗と記録を確認します。停止・再開の操作も上部に表示します。
5. レビュー待ちになったら「レビュー依頼をコピー」で左のChatGPTへ戻り、レビューを依頼します。
6. 返ってきたReview ManifestをLocaloudで取り込みます。合格したら完了です。

左でタスクを選んでも、ChatGPTの会話を自動対応付けしません。レビュー依頼に含まれるTask IDと成果物の版で対象を確認してください。

### 修正と再レビュー

`依頼 → 計画 → 実行 → レビュー → 完了` のうち、修正対象のあるレビューを取り込むと **実行に戻ります**。対象の担当と依存先を再実行し、新しい成果物を再レビューします。「2回目の実行」などの表示で繰り返しを区別します。

不合格・判定保留で修正対象の指示がない場合は、レビュー工程で追加の指示を待ちます。失敗・中断は完了にせず、実行工程に状態確認・再開を表示します。

## ChatGPTを使わない場合

開始方法で「直接依頼」を選び、Localoudの入力欄から送信します。ChatGPTは閉じて構いません。直接依頼を選んだ設定は次の新規タスクにも引き継ぎ、非表示のChatGPTに計画を入れることは要求しません。

工程は `依頼 → 実行 → 完了` です。実行中の入力は追加指示として送り、停止は上部で行います。モデル・思考量、参照ファイル、スキルなどは既存の入力機能を使います。直接実行の完了を、ChatGPTレビュー合格とは表示しません。

ChatGPTペインの表示と実行方法は別です。直接依頼のままChatGPTを開いて相談することもできます。

## 記録タブ

| タブ | 内容 |
| --- | --- |
| 概要 | 依頼、担当全体の進捗、レビュー結果、完了条件、作業ID・保存先。直接依頼では会話と入力欄 |
| 計画 | 取り込んだ担当・目標・範囲・前提関係・完了条件 |
| 変更 | 実行中は担当別、統合後は統合成果物の差分。新規ファイルを含む |
| 担当 | 状態・範囲・最新メッセージ・完了報告 |
| ログ | 実行コマンド・出力・終了コード・検証記録 |
| 参照情報 | このタスクの担当に実際に渡した指示 |
| 使用量 | 担当ごとの最新の保存記録。Codexはセッション累計（過去の実行を含む場合あり）、ローカルは生成1回分 |

計画・モデル・実行の編集操作を記録タブ内に置きません。長い出力のみ枠内スクロールとし、開閉状態とスクロール位置はタブ移動・更新で保持します。

## ChatGPTの参考カウンター

ChatGPT上部の「回数を記録」で、送信したモデルの `Astra +1` または `Sol +1` を押します。自動送信・自動計測・自動モデル変更は行いません。推奨はAstraを優先します。

- ユーザー指定の参考枠: AstraとSolの合計が週200回。Solはさらに1日170回。
- 週は月曜日0時、日は毎日0時の端末時刻で区切ります。
- このアプリ内で手動記録した分だけです。他の画面で使った分や導入前の利用は含みません。
- 「リセット」は表示中の週・日のカウントをゼロに戻します。「取り消す」で直前の加算やリセットを戻せます。
- OpenAI側の正式な残量やリセット日時を取得したものではありません。Codex workerのトークン使用量とも別です。

## 境界と検証

ChatGPT本文のDOM操作・抽出・自動送信は行いません。Task ManifestとReview Manifestはユーザーが明示的に取り込みます。成果物のレビュー合格は、元プロジェクトへのマージ・公開完了を意味しません。

フロントエンド検証では、直接依頼の送信・追加指示・完了・次タスクへのモード保持、レビュー修正時の工程、計画取り込み、幅・表示状態の保持、週と日をまたぐカウントを確認します。UI変更の検証を新しい実workerの品質評価とは扱いません。
