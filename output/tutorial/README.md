# Localoud 操作ガイド

> この動画は2026-09-09のUX再設計前の画面です。以下の操作名も撮影時点のものを保持しています。現在の操作は [作業フロー](../../docs/WORKFLOW_UX.md) を参照してください。


`localoud-guide.webm` は、日本語字幕付きの実画面による解説動画です。Tauriウィンドウで行った操作の静止画を拡大し、Playwrightで動画化しています。連続したネイティブ画面録画ではありません。音声はありません。

接続設定が完了した状態から、計画、取り込み、実行結果の確認、レビュー、完了までを説明します。実行とレビューは先ほど完了したテストの保存結果です。撮影では同じTask ManifestとReview Manifestを取り込み直して既存タスクを開き、新しいworkerは起動していません。

## 操作の順序

1. 左で対象プロジェクトを選び、「新しいタスク」を押す。操作は「Manifestを実行」。
2. 右のChatGPTでLocaloudプラグインを選び、MCPで対象を確認してTask Manifestを返すよう依頼する。
3. JSONコード枠のコピーを押し、左の「貼り付けて実行」を押す。
4. 取り込み結果と状態を確認し、Agentsで担当・モデル・各workerの状態、Chatで検証結果を確認する。
5. 統合後に表示されたタスクIDを渡し、ChatGPTへMCPでのレビューとReview Manifestを依頼する。
6. レビューJSONをコピーし、同じ「貼り付けて実行」で戻す。合格レビューが取り込まれたら「完了」を確認する。

## 計画の依頼例

```text
Localoud MCPで project_list と handoff_schema を読み、対象プロジェクト「＜プロジェクト名＞」を確認してください。
＜作業内容＞を実装するTask Manifestを作ってください。
変更範囲は＜対象ファイル・ディレクトリ＞、合格条件は＜期待する結果＞です。
正しい形式のJSONコードブロック1個で返してください。
```

## レビューの依頼例

```text
Localoud MCPでタスク ＜表示されたタスクID＞ の最新成果物・差分・検証結果をレビューし、Review Manifestを返してください。
```

## 補足

- 同じManifestを再度取り込むと、二重実行せず保存済みタスクを開きます。
- 中断したタスクは「再開・状態を確認」を使います。
- 動画収録後の更新で、Diffタブは実際の作業フォルダを参照し、未追跡の新規ファイルも表示するようになりました。ChatとAgentsにはworkerごとの進捗、Terminalには実行履歴を表示します。
- 修正指示が返されたら、修正後の最新成果物に対して再レビューします。

`record.mjs` が動画生成スクリプト、`browser-diagnostics.json` が録画用ブラウザの診断記録です。PNGは実画面素材です。
