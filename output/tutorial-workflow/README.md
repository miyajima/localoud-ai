# 改善版UIの操作ガイド

2026-09-09のLocaloud実画面を操作・撮影し、Playwrightで字幕と章立てを付けた解説動画です。ネイティブアプリの連続画面録画ではありません。旧版動画は `../tutorial/` に保存しています。

1. プロジェクトとタスク、上部の5工程を確認
2. 依頼を入力してコピーし、ChatGPTで計画を相談
3. 確定した計画JSONを上部から取り込む操作箇所を確認
4. 計画・担当・変更・ログ・参照情報・使用量の記録を確認
5. レビュー依頼と結果取り込みの手順を説明し、完了例を確認

今回実際に行ったのは、画面選択、録画用依頼文の入力・コピー、保存済みタスクの閲覧です。ChatGPTへの送信、新しい計画やレビューの取り込み、workerの起動は行っていません。計画取り込み・レビュー待ちの操作は字幕で説明しています。画面内の完了は過去に保存された実行とレビューの結果です。

- `localoud-workflow-guide.webm`: 日本語字幕付き・無音
- `record.mjs`: ローカル画像から動画を再生成するスクリプト
- `execution-logs.json`: 章・場面・撮影画像
- `browser-diagnostics.json`: Playwright動画生成時の警告・エラー・失敗リクエスト
- `qa/`: 各場面の検証画像

最新版の操作仕様: [WORKFLOW_UX.md](../../docs/WORKFLOW_UX.md)
